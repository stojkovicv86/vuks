Verify crawler IPs

Anyone can put "Googlebot" in a user agent. Google, Bing, Apple, Yandex and Baidu crawlers can be confirmed with a reverse DNS lookup followed by a forward lookup, the method these search engines document.

This is the only step that uses the network: it sends the listed crawler IP addresses, and nothing else, to Google Public DNS (dns.google). The log itself stays in your browser.

Guide

Why log files matter for SEO

Every SEO tool simulates a crawler. Your server logs record the real one. Each line is a request Googlebot or an AI crawler actually made, with the URL, the status code it got and the exact time. That makes logs the only direct answer to questions like: is Google crawling the pages that matter, how much crawl goes to redirects and junk URLs, how quickly new content is discovered, and which AI crawlers are reading the site.

What to look for

Crawl waste

Requests to redirects, 404s, parameter URLs, internal search and faceted navigation are requests not spent on pages that can rank. On small sites this rarely matters. On sites with tens of thousands of URLs, it decides how fast new and updated pages are picked up.

Pages Googlebot never visits

Compare the log with your sitemap. Important URLs with no Googlebot request in 30 days are usually poorly linked internally, too deep in the structure, or seen as low value. That list is often more useful than any crawl report.

Server errors

5xx responses tell Google the server is struggling, and Google slows down crawling in response. A few on one day can be noise. Errors every day, or a spike after a release, need a developer.

Smartphone vs desktop Googlebot

With mobile-first indexing, the large majority of Googlebot requests should come from the smartphone crawler. A site still crawled mostly by desktop Googlebot is worth checking in Search Console.

AI crawlers

GPTBot, ClaudeBot, OAI-SearchBot, PerplexityBot and others now show up in most logs. The report separates AI search crawlers, user-triggered fetchers and training crawlers, so you can see whether your robots.txt rules or CDN settings are doing what you intended. A wall of 403 responses usually means a firewall is blocking them, not robots.txt.

Fake Googlebots

Scrapers often pretend to be Googlebot. The verification step does a reverse DNS lookup on each IP, checks that the hostname belongs to the search engine (for example googlebot.com or search.msn.com), then confirms it with a forward lookup. Requests that fail are not Google, whatever the user agent says.

Supported log formats

  • Apache and Nginx common and combined formats, including virtual-host prefixes and extra fields after the user agent.
  • W3C extended (IIS), using the #Fields header.
  • JSON lines from Cloudflare Logpush and most log pipelines. Common field names for IP, URL, status, user agent and time are detected automatically.
  • Gzipped files are unzipped in the browser while they are read.

What this tool does not do

It does not fetch any page, and it only knows what your logs contain. Logs behind a CDN may show cached responses, or miss requests the CDN answered on its own. If your host only keeps a few days of logs, ask for longer retention before you draw conclusions about crawl frequency.

FAQ

Are my log files uploaded anywhere?

No. Files are read and analysed by JavaScript in your browser, line by line. The only optional network request is the IP verification step, which sends crawler IP addresses to Google Public DNS.

How big can the log files be?

Files are streamed, so hundreds of megabytes work in a modern browser. Only crawler requests are kept in detail; visitor traffic is counted but not stored, which keeps memory use low.

How many days of logs do I need?

At least two weeks, ideally 30 days or more. Googlebot visits important pages often, but deeper pages may only be requested every few weeks, so short samples overstate how many pages are never crawled.

Why do I see fewer Googlebot requests than Search Console reports?

Search Console's crawl stats cover every host Google crawls for the property, including CDN and image hosts, and every Google crawler. Your log may only cover one server or one host. Compare like for like.

How do I verify Googlebot without sending IPs to Google DNS?

Run the same check on your own machine: host 66.249.66.1, then host on the returned name. Or compare the IPs against the googlebot.json IP ranges Google publishes.

Does it work with Cloudflare?

Yes, with Cloudflare Logpush HTTP request logs in JSON format. Fields like ClientIP, ClientRequestURI, EdgeResponseStatus and ClientRequestUserAgent are recognised.
